# price-simulator
EC通販業務向けのローカル完結型「販売価格設定・利益シミュレーター」。仕切価格と複数運送会社（郵便・佐川・ヤマト）の地域別最安平均送料から、係数別の販売基準価格・セット販売比較・改善提案を1画面で算出します（単一HTML・外部依存なし）。

# 販売価格設定・利益シミュレーター

EC通販業務において、商品の仕切価格と運送会社ごとの運賃表から「利益が成立する販売価格・販売条件」を判断するためのローカル完結型Webアプリケーションです。

## 主な機能

* **地域別・最安値平均送料の自動算出**
  * 利用する運送会社（郵便・佐川急便・ヤマト運輸）をチェックボックスで選択し、各地域の最安運賃を自動採用して平均送料（税抜）を算出します。
  * 佐川急便の「120サイズは140サイズ料金を適用」ルールに対応しています。
  * 未登録の運賃（空欄）は `0円` として扱わず、自動的に平均計算から除外して警告を表示します。
* **送料見積もり対象地域の切り替え**
  * **なし**：全地域の最安値平均
  * **パターンA**：北海道・沖縄・離島を除外した地域の最安値平均
  * **パターンB**：北海道・東北・沖縄・離島を除外した地域の最安値平均
  * 個別地域ごとのチェック変更にも対応しています。
* **最安送料の直接登録・運賃表の編集**
  * メール便や特約運賃など、運賃表にない最安送料（税抜）を直接入力して計算に反映できます。
  * 画面内の地域別送料一覧から、未登録運賃の追加や金額の修正をその場で行えます。
* **係数別の販売基準価格シミュレーション**
  * 利益設定係数（`0.70` / `0.75` / `0.80` / `0.85` / `0.90`）ごとの販売基準価格、計算上の粗利・粗利率、社内赤字ライン（0.90）の判定を一覧表示します。
  * 任意で販売手数料率を入力すると、手数料控除後の参考利益も確認できます。
* **セット販売比較（1〜4個）**
  * 1個〜4個セットそれぞれについて、同梱後の梱包サイズを個別に指定し、販売基準価格および1個あたりの送料負担を比較できます。
* **販売方法の改善提案**
  * 見積もり対象地域の拡大（パターンBへの変更）やセット販売による送料圧縮効果など、計算根拠付きで改善案を提示します。
